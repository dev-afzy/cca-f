# User Auth + OAuth Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the single-`"default"`-student app into multi-user with Auth.js (NextAuth v5) GitHub + Google sign-in, each user scoped to their own Student profile/mastery/exam data, with the existing `default` data claimed on first login.

**Architecture:** Auth.js v5 with the Prisma adapter (stores `User`/`Account`/`VerificationToken`) and **JWT sessions** (no auth `Session` table → no clash with the app's tutoring `Session` model). `Student.id` equals the authenticated `User.id` **by convention** (no DB FK — a hard FK would violate against the legacy `default` row). The `Student` model is left unchanged (its `@default("default")` is harmless because `ensureStudent` always passes an explicit id), so the migration is purely additive. Every route/page resolves the logged-in user via `requireUser*` helpers and passes that id into the already-`studentId`-parameterized libs.

**Tech Stack:** Next.js 16 App Router, next-auth@beta (v5), @auth/prisma-adapter, Prisma 7 + libsql, Tailwind v4.

## Global Constraints

- **Node ≥ 22** for all `npm`/`prisma`/`tsx`/`build` commands (subagent shells default to Node 14): run `nvm use 22` or ensure `node -v` ≥ 22 first.
- **Session strategy is JWT** (`session: { strategy: "jwt" }`). Do NOT add an auth `Session` model — the tutoring `Session` model must stay untouched.
- **Do NOT modify the `Student` model** (keep `id String @id @default("default")`). Auth tables are additive only.
- **Student.id == User.id by convention** — no Prisma relation/FK between them. `ensureStudent(userId)` always supplies `id: userId`.
- **Providers:** GitHub + Google, each `allowDangerousEmailAccountLinking: true`. Env var names follow Auth.js auto-detection: `AUTH_SECRET`, `AUTH_GITHUB_ID`, `AUTH_GITHUB_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_URL`.
- **Gating:** `/chat`, `/exam/*`, `/ledger` redirect to `/login` when logged out (middleware). All `/api/*` app routes (turn, turn/retry, exam/{start,answer,submit}, session/end, ledger, ledger/sync) return **401** when logged out. `/` is public.
- **No live-OAuth verification** in this plan — the user supplies provider creds later. Verify via `npm run build`, `npm run validate:content`, and unauth redirect/401 checks. `auth()` returns null without a session cookie.
- DB path `~/.cca-f-tutor/cca-f.db`; back up before any `db:setup`.
- No test framework — verify with `tsx` throwaways + build + curl; delete throwaways, never commit them.

**Files:**

**Interfaces:**
- Produces:

  - `requireUserIdApi(): Promise<string | null>` — API routes; returns the id or `null`.

- Consumes: `auth` from `@/lib/auth`; `prisma`.

- [ ] **Step 2: ensure-student.ts**

```typescript
import "server-only";
import { prisma } from "@/lib/prisma";

const SPRINT_DAYS = 23;

/**
 * Make sure a Student profile exists for this authenticated user.
 * Idempotent. On the very first sign-in, if the legacy unclaimed
 * Student id="default" exists, re-key it to this user (FKs cascade on update);
 * otherwise create a fresh Student with 0% masteries for every concept.
 */
export async function ensureStudent(userId: string): Promise<void> {
  const existing = await prisma.student.findUnique({ where: { id: userId } });
  if (existing) return;

  await prisma.$transaction(async (tx) => {
    // Re-check inside the tx to avoid a race between two simultaneous first logins.
    if (await tx.student.findUnique({ where: { id: userId } })) return;

    const def = await tx.student.findUnique({ where: { id: "default" } });
    if (def) {
      await tx.student.update({ where: { id: "default" }, data: { id: userId } });
      return;
    }

    const now = new Date();
    const startOfTodayUtc = new Date(
      Date.UTC(now.getUTCFullYear(), now.getUTCMonth(), now.getUTCDate())
    );
    const targetExamDate = new Date(startOfTodayUtc.getTime() + SPRINT_DAYS * 86400000);
    await tx.student.create({
      data: { id: userId, sprintStartDate: startOfTodayUtc, targetExamDate },
    });
    const concepts = await tx.concept.findMany({ select: { id: true } });
    if (concepts.length) {
      await tx.conceptMastery.createMany({
        data: concepts.map((c) => ({ studentId: userId, conceptId: c.id, mastery: 0 })),
      });
    }
  });
}
```
